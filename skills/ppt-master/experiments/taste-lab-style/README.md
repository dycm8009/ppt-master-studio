# Taste Lab Style pilot

`taste-lab-style` is an explicit, unregistered Style workspace for Phase 2 of the Taste Skill / Humanizer integration plan.

## Activation

Supply this exact workspace root to a Generate request:

```text
skills/ppt-master/experiments/taste-lab-style
```

The workspace is not present in `templates/styles/styles_index.json`, so ordinary template discovery cannot select it. The normal Stage 1 template choice, installation handoff, Stage 2 confirmation, and Style precedence remain unchanged.

## Scope

The pilot adapts presentation-relevant concepts only:

- brief inference from audience, context, references, brand assets, and quiet constraints;
- composition variance, motion purpose, and information density as internal design lenses;
- anti-default review for generic AI visual habits;
- audit-first redesign behavior;
- cross-page composition and rhythm review.

It excludes web frameworks, scrolling, navigation, CTA, form, mobile, performance, mandatory randomization, static-is-failure behavior, and global bans that conflict with PPT Master.

## Promotion gate

Do not move this workspace into the registered Style library until the Phase 3 A/B evaluation shows a consistent target-scenario benefit without factual, template, or Visual Review regressions.
