# Experimental PPT Master assets

This directory contains explicit workspaces and evaluation packages that are intentionally absent from the registered template indexes.

An experimental workspace is usable only when the caller supplies its exact root. It must not appear in Stage 1 library discovery, and it must not be promoted into a registered Brand, Style, Layout, or Deck until its documented evaluation gate passes.

| Path | Kind | Status |
|---|---|---|
| `taste-lab-style/` | Style workspace | Phase 2 pilot for the Taste Skill integration plan |
| `taste-humanizer-eval/` | Evaluation protocol | Phase 3 harness implemented; real deck evidence pending |

Experimental assets remain subject to normal validation, confirmation, ownership, provenance, and precedence rules. Their location creates no new route or relaxed contract.
