# PPT Master Studio v3.2.0 — Template Rules

## General + Dark Tech
Use deep charcoal/navy solid surfaces, sparse native geometry, restrained accents, thin separators, and SVG-native technical diagrams. Information structure should carry the visual.

Preferred carriers: architecture/network, process/pipeline, comparison, matrix/table, continuum/spectrum, editorial statement, typography-led breathing page, bounded evidence screenshot when identity/evidence matters.

Raster backgrounds, ambient raster backgrounds, full-bleed AI illustration, dense HUD concept art, decorative concept art, and high-detail imagery behind normal content are forbidden by default. Evidence screenshots and supporting figures are allowed when semantically necessary and placed in bounded containers.

Suggested ceilings, never quotas: max image area 38% of a slide; image-dominant slides 12%; AI-illustration slides 6%. Zero raster images is valid.

Motion defaults: transition `none`; restrained 0.2–0.35s fade only at justified section boundaries; Morph only for true semantic continuity; no motion merely because an object exists.
