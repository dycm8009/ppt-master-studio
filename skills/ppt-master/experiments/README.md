# Experimental PPT Master workspaces

This directory contains explicit workspaces that are intentionally absent from the registered template indexes.

An experiment is usable only when the caller supplies its exact workspace root. It must not appear in Stage 1 library discovery, and it must not be promoted into a registered Brand, Style, Layout, or Deck until its documented evaluation gate passes.

| Workspace | Kind | Status |
|---|---|---|
| `taste-lab-style/` | Style | Phase 2 pilot for the Taste Skill integration plan |

Experimental workspaces remain subject to the normal validation, installation, confirmation, ownership, and precedence rules. Their location creates no new route or relaxed contract.
